# 미션 2-1 | 나만의 프롬프트 관리 프로그램

Python 3.10 이상과 Git 기초를 연습하기 위한 **콘솔 기반 프롬프트 관리 프로그램**입니다. 외부 패키지는 사용하지 않습니다.

## 실행 방법

1. VSCode에서 이 폴더를 엽니다.
2. Python 확장을 설치하고 Python 3.10 이상을 선택합니다.
3. 터미널에서 다음 명령을 실행합니다.

```bash
python3 --version
python3 main.py
```

Windows 환경에서는 `python main.py`를 사용할 수 있습니다.

## 기능

| 메뉴 | 기능 |
|---|---|
| 1 | 제목, 내용, 카테고리를 입력해 프롬프트 추가 |
| 2 | 전체 프롬프트 목록 보기 |
| 3 | 카테고리별 조회 |
| 4 | 제목 또는 내용의 키워드 검색 |
| 5 | 프롬프트 전체 내용 보기 |
| 6 | 즐겨찾기 추가/해제 |
| 7 | 즐겨찾기 목록 |
| 0 | 종료 |

- 데이터는 **리스트 안의 딕셔너리**로 관리합니다.
- 프로그램 실행 중 추가/변경한 데이터는 유지되지만 종료 후 초기화됩니다.
- 기본 카테고리: 텍스트 생성, 이미지 생성, 영상 생성, 페르소나, 자동화, 기타
- 직접 입력한 카테고리도 조회할 수 있습니다.
- 초기 데이터 3개는 **예시**입니다. 제출 전 반드시 이전 미션에서 본인이 만든 프롬프트 3개 이상으로 교체하세요.
